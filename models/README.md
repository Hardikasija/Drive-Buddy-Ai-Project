# Final model artifact

`final_model.joblib` is generated by the training pipeline from the exact leakage-controlled final model.

Run:

```bash
python src/DrivebuddyAI_PavBhaji_Challenge.py --data-dir <path_to_dataset> --output-dir outputs
```

The pipeline will create:

```text
models/final_model.joblib
outputs/model_metadata.json
```

Do not replace the artifact with a separately retrained or differently preprocessed model if the Streamlit demo is being used to demonstrate the submitted solution.
